■ 必須条件
- CDS / annotation を優先し、標準 CRUD を不要に置換しない。
- 実装は TypeScript で行い、strict な型チェックを維持する。入力・外部応答は runtime でも検証する。
- action は CDS と this.on、複数更新は cds.tx(req) を用いる。
- 認証情報をコード・ログに残さず、外部連携は Destination 等の設定を使う。
- npm run lint、npm test、npm run build（存在するもの）を実行し、結果を報告する。

■ AI に提出してほしいもの

■ 受入条件
- 指定ロールで CRUD と action が正しく動作する。
- 業務エラー、認可エラー、外部失敗が利用者向けに処理される。
- 親子の整合性を保存時に保証し、型チェック・テストが成功する。
