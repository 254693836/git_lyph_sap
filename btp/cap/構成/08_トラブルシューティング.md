# トラブルシューティング

## 基本の確認順

1. `npm install` が完了しているか確認します。
2. `cds watch` の起動ログで、コンパイルエラーとサービスURLを確認します。
3. `$metadata` とEntity Setを直接開き、サービス層から確認します。
4. イベントハンドラ、認可、UIアノテーションの順に範囲を絞ります。

## よくある問題

| 症状 | 主な原因 | 対処 |
| --- | --- | --- |
| `cds watch` が起動しない | 依存関係未導入、CDS構文エラー | `npm install`、エラー行の確認 |
| EntityがODataに出ない | serviceでProjection未定義 | `srv/*.cds` の `entity ... as projection` を確認 |
| CRUDが失敗する | 必須項目、型、関連設定の不整合 | HTTP応答、`db/schema.cds`、リクエストを確認 |
| Actionが404になる | サービス定義とJSハンドラ名の不一致 | `action` 名と `this.on()` 名を一致させる |
| Fioriに項目が出ない | UI annotation未設定、対象Entity違い | annotationのターゲットとメタデータを確認 |
| 403になる | `@requires`／`@restrict` とロール不一致 | 認証情報とロールコレクションを確認 |
| HANAでだけ失敗する | SQLiteとHANAのSQL差、デプロイ設定 | HANAでのテスト、`cds deploy --to hana`設定を確認 |

## 調査に役立つコマンド

```bash
cds watch
cds compile '*'
cds lint
npm test
```

## 問題報告に残す情報

- 実行したコマンドと再現手順
- HTTPメソッド、URL、リクエスト本文
- HTTPステータス、応答本文、サーバーログ
- 使用したNode.js、CAP、DBのバージョン
- ローカルだけかBTPでも起きるか
