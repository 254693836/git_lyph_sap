以下の要件を満たすABAPプログラムを実装してください。

【基本要件】
・実装言語：ABAP
・プログラム種別：Report Program
・実装コードの格納先：Z_087_PROGRAM_ANALYSIS.txt
・対象システム：SAP ABAP
・目的：指定したABAP Report Programのソースコードを解析し、処理構造を階層形式で表示する

【機能要件】

1. Report Programの入力

Selection Screenに、解析対象となるABAP Report Program名の入力項目を設けてください。

例：
PARAMETERS p_prog TYPE progname.

1-1. 検索ヘルプ

入力項目でF4キーを押した場合、Report Programを検索・選択できるようにしてください。

検索対象は、SAP標準テーブルから取得してください。

以下の条件を満たすプログラムのみを検索対象とします。
・プログラム名が「Z」で始まるもの
・プログラム名が「Y」で始まるもの

1-2. 検索ヘルプの実装方法

SE11でSearch Helpオブジェクトを新規作成しないでください。

ABAP Report Program内で、
AT SELECTION-SCREEN ON VALUE-REQUEST
などを利用して、F4検索機能を実装してください。

必要に応じて標準Function Module等を利用して構いません。


2. ABAPプログラムの解析

入力されたReport Programのソースコードを取得し、そのプログラムの処理構造を解析してください。

単純にソースコードを表示するのではなく、
FORM、METHOD、FUNCTION等の処理単位と、それらの呼び出し関係を解析してください。

可能な範囲で、各処理の直前または内部に記述されているコメントも取得し、
その処理の説明として表示してください。


3. 呼び出し関係の階層化

プログラムの開始処理から、呼び出される処理を順番に解析し、
親処理 → 子処理 → 孫処理
という階層構造で表示してください。

例えば、以下のようなABAPコードが存在するとします。

START-OF-SELECTION.
  PERFORM main.

FORM main.
  PERFORM initial.
  PERFORM get_xxxx.
  PERFORM update_xxxx.
ENDFORM.

FORM get_xxxx.
  PERFORM get_filter_info.
  PERFORM get_xxxx_info.
ENDFORM.

この場合、解析結果を以下のように表示してください。

① main（メイン処理）
    ①-1 initial（初期化処理）
    ①-2 getXXXX（XXXX情報取得処理）
        ①-2-1 getFilterInfo（フィルター情報取得処理）
        ①-2-2 getXXXXInfo（XXXX情報取得処理）
    ①-3 updateXXXX（XXXX情報更新処理）


4. 解析対象

少なくとも以下を解析対象としてください。

・START-OF-SELECTIONなどのReport Event
・PERFORM ～ FORM
・メソッド呼び出し
・CALL FUNCTION
・可能であればINCLUDEプログラム

特にPERFORMについては、
呼び出し先のFORMの内部も再帰的に解析し、
さらにPERFORMが存在する場合は下位階層として表示してください。


5. コメントの解析

処理名だけでなく、可能な範囲でABAPソースコードのコメントを解析し、
各処理の説明として表示してください。

例：

*---------------------------------------------------------------------*
* メイン処理
*---------------------------------------------------------------------*
FORM main.

の場合、

main（メイン処理）

のように表示してください。


6. 注意事項

・解析対象プログラムそのものは変更しないこと
・SE11でSearch Helpを新規作成しないこと
・Z/Yプログラムを対象とすること
・呼び出し関係は可能な限り再帰的に解析すること
・同じ処理を循環して呼び出している場合、無限ループにならないようにすること
・存在しないプログラムが入力された場合は、適切なエラーメッセージを表示すること
・標準ABAP機能を優先して使用すること

以下の要件を満たすSAP ABAP Report Programを作成してください。

## 成果物

- 実装言語：ABAP
- プログラム種別：Executable Report Program
- ソースコードの保存先：Z_087_PROGRAM_ANALYSIS.txt
- 対象SAP環境：［例：SAP NetWeaver 7.31／S/4HANA 202x］
- ABAP構文互換性：［例：NetWeaver 7.31互換。文字列テンプレート |...|、インライン宣言 DATA(...)、テーブル式、VALUE #、新しいOpen SQLの @ は使用しない］
- コード中のコメント：日本語
- 対象プログラムを更新・ロック・変更しないこと

## 目的

Selection Screenで指定したZ/Yレポートプログラムのソースコードを参照し、
処理単位と呼出し関係を解析して、階層形式で一覧表示してください。

単にソースを出力するのではなく、処理単位ごとの呼出し構造を表示してください。

## 入力画面

以下の入力項目を作成してください。

PARAMETERS p_prog TYPE progname OBLIGATORY.

- 入力対象はZまたはYで始まるプログラム名だけとする
- 存在しないプログラム、またはレポートプログラム以外が指定された場合はエラーにする
- F4検索を実装する
- SE11でSearch Helpオブジェクトは作成しない
- `AT SELECTION-SCREEN ON VALUE-REQUEST` と標準Function Moduleを使用する
- 検索候補は標準テーブルTRDIR/TRDIRTから取得する
- 検索対象はZまたはYで始まる実行可能レポートだけとする

## ソース取得

- `READ REPORT` を使用してソースを取得する
- INCLUDEも解析対象に含める
- 標準テーブルD010INCを利用し、直接INCLUDEだけでなく下位INCLUDEも再帰的に読み込む
- 同じINCLUDEを複数回読み込まないこと
- INCLUDEの循環参照で無限ループしないこと
- ソースを変更しないこと

## 解析対象の処理単位

以下を検出し、処理単位として登録してください。

- Report Event
  - INITIALIZATION
  - AT SELECTION-SCREEN
  - START-OF-SELECTION
  - END-OF-SELECTION
  - TOP-OF-PAGE
- FORM ... ENDFORM
- METHOD ... ENDMETHOD
- MODULE ... ENDMODULE
- FUNCTION ... ENDFUNCTION

各処理単位について、以下を保持してください。

- 種別（EVENT / FORM / METHOD / MODULE / FUNCTION）
- 処理名
- 定義元プログラム名またはINCLUDE名
- 開始行・終了行
- 直前のコメントから取得した説明文

## 呼出し関係の解析

少なくとも以下を解析してください。

- `PERFORM xxx`
  - 呼出し先FORMを解決する
  - FORM内のPERFORMも再帰的に解析する
- `CALL FUNCTION 'xxx'`
  - 取得済みソース内にFUNCTION定義がある場合はリンクする
  - 定義がない場合は外部FUNCTIONとして表示する
- インスタンスメソッド呼出し：`object->method`
- 静的メソッド呼出し：`class=>method`

解析できない動的呼出しは、エラーにせず「動的呼出し／未解決」として表示してください。

同じ処理を循環して呼び出す場合は、循環参照として表示し、それ以上は再帰展開しないでください。

## コメント解析

FORM、METHOD、MODULE、FUNCTIONの直前にあるコメントを説明として表示してください。

例：

*---------------------------------------------------------------------*
* メイン処理
*---------------------------------------------------------------------*
FORM main.

上記の場合は、以下のように表示してください。

main（メイン処理）

罫線だけのコメントは説明文として採用しないでください。

## 出力要件

WRITE文などで階層形式に表示してください。

例：

解析対象: Z_SAMPLE_REPORT

処理構造
1 START-OF-SELECTION [EVENT]
1-1 MAIN（メイン処理） [FORM]
1-1-1 INITIALIZE（初期化処理） [FORM]
1-1-2 GET_DATA（データ取得処理） [FORM]
1-1-2-1 GET_DETAIL [FORM]
1-1-3 Z_SAMPLE_FUNCTION [FUNCTION]

未呼出しの処理単位
2 F4_PROGRAM [FORM]
3 MODULE_STATUS_0100 [MODULE]
4 UNUSED_FORM [FORM]

重要事項：
- イベントから到達できる処理だけでなく、読み込んだメインプログラムおよび全INCLUDE内で検出した全処理単位を表示すること
- 呼出し元がない処理は「未呼出しの処理単位」セクションに表示すること
- 同じ処理を複数経路から呼び出す場合は、呼出し関係を優先して表示してよい
- 循環参照は明示して無限再帰しないこと

## 実装品質

- 処理をFORMルーチンなどへ分割し、主要処理に日本語コメントを付ける
- ABAP構文エラーがないようにする
- 成果物は指定ファイルへ完全なソースコードとして保存する
