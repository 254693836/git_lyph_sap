# 第6部：組織構造・会計期間・伝票制御（第51〜100問）

C_TS4FI（Private Edition）を主対象とするオリジナル問題。各セット10問の後に解答・解説を掲載します。標準設定を前提とし、顧客固有の設定では異なる場合があります。

| 54 | **D** | セグメント情報は事業区分別報告に使う。 |
| 55 | **A** | プラントは物流と会計の連携点。 |
| 56 | **B** | 購買組織は会社コード横断の設定も可能。 |
| 57 | **C** | 販売組織は売上処理の組織要素。 |
| 58 | **D** | 会社は会社コードとは異なる連結用途の組織単位。 |
| 59 | **A** | 収益性分析領域はCO-PAの組織単位。 |
| 60 | **B** | 減価償却表は会社コードに割り当てて資産評価領域を定義する。 |
