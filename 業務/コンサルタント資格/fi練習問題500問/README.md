## 学習順序と到達目標

1. **基礎（1〜150問）**：各セット80%以上。組織、勘定コード表、転記期間、G/L、税、通貨を説明する。
2. **業務別（151〜350問）**：各セット85%以上。AP・AR・銀行・固定資産の業務と仕訳を説明する。
3. **決算・連携（351〜400問）**：85%以上。決算、外貨評価、残高繰越、MM/SD/CO連携を説明する。
4. **実務・総合（401〜500問）**：90%以上。エラー原因、設定確認、移行、テストを自力で説明する。
5. **実機演習**：会社コード・G/L・BP・支払条件・自動支払・固定資産・外貨評価をSAP環境で操作し、転記結果とログを検証する。

※正答率は自主学習の目標で、SAP公式試験の合格基準ではありません。

## 復習方法

- 1日20〜30問。誤答は正解理由、他選択肢の誤り、SAP実機で確認する場所を記録する。
- 50問ごとに復習し、3日後・1週間後に誤答を解き直す。
- T-codeは主にS/4HANA Private EditionのSAP GUIを前提とする。顧客設定やリリースによる差異に注意。
- 一部に類似知識の反復問題がある。実技対策は別途必要。
